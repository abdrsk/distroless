# CONTRIBUTING

We are very welcome to contributions.

## Guidelines

We accept PR's if we think it is helpful to the project.
If we think that the changes are not OK for super-normies (like using
words they might not be familiar with), we will kindly reject the PR's
or ask you for changes.

AI *is* allowed *but*:

- You have to have a notice on the PR that you used AI and where.
- You dont let AI write *any* informative text; AI might only be
used for designing purposes only and has to be formatted correctly
(preferably by a human)
